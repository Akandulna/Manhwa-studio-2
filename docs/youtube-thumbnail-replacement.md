# Replace a selected YouTube thumbnail

The selected thumbnail card, imported-image generation dialog, and enlarged preview include **Replace thumbnail**, opening a PNG/JPEG/WebP file picker. A successful upload immediately becomes the selected image for the current title. The prior image stays in All variations and can be selected again. Uploads use the existing 20 MB / 40 megapixel still-image decoding and PNG normalization rules. Invalid uploads and conflicting workspace revisions leave the current selection unchanged.

Replacement uploads are immutable thumbnail versions with source=uploaded, nullable requestId/slot, and replacesId pointing to the previous selected version. When replacing an imported variation for the current title, the new version retains its request/slot association and the generation dialog shows the newest image in that slot. Earlier images remain available in All variations. Replacements for another title or standalone uploads have no request/slot association. Existing generated versions remain compatible. Uploads need an existing selected thumbnail and a current title, but do not require crop references or a new generation request. A replacement clears the previous-title review flag by associating the uploaded image with the current title. Uploaded versions support existing copy/download, selection restoration, and use as the parent image for feedback-based generation.

The multipart replace endpoint is series-scoped and requires the expected workspace revision plus the selected image ID. This prevents stale windows from replacing a different current selection. Prior files and generation prompts are retained. The UI identifies uploads separately from generation batches.

Validation: 59 YouTube tests, server/client TypeScript and web bundle build. Isolated Chromium checks cover the file picker, rejected corrupt image without selection loss, successful replacement, restoring either image, persistence after reload, uploaded-image refinement, and the narrow layout. Only synthetic QA series data was used.
