## What is shared

Model/mode/effort controls need explicit supported-policy work and their own acceptance tests before use.

Plan and profile are context; the observed page controls and accepted variant evidence determine UI compatibility. Do not assume every Go or Plus profile has the same DOM. Existing fixture coverage is not installed-profile acceptance.
