# Hinglish thumbnail and generation popup controls

The existing Thumbnails tab shows English and Hinglish cards side by side. Hinglish reuses the current selected thumbnail and overlays original extra-bold Latin HINDI lettering. The default is yellow with an outline, at bottom right with padding. Copy image and Download PNG include the overlay. Selecting or replacing the English image updates the Hinglish base automatically; the selected series style is retained.

Edit opens a popup with a live preview, drag and keyboard positioning (arrow keys; Shift for larger steps), size and position sliders, corner/center presets, six color swatches and a custom color picker. Four templates are available: Classic outline, Shadow, Italic and Badge. Reset restores defaults; Cancel discards changes; Save persists the style per series. Preview and PNG export use the same original SVG paths, independent of installed fonts. Dark text automatically receives a light outline.

The optional workspace hindiOverlay field contains template, six-digit hex color, size (10–60 percent), x and y (0–100 percent of available placement space). PNG export preserves original image dimensions, constrains the overlay inside the image, validates source image integrity and leaves original bytes unchanged. Revision and base-image checks reject stale saves; the export style key rejects outdated copy/download requests. Existing workspaces use defaults without requiring data migration. Hinglish readiness becomes Done when its title, description and valid selected base image exist; stale title/thumbnail review flags still apply.

Title and description generation popups now show Copy prompt and Paste response as adjacent action buttons, with an always-visible response box and direct save/import action. A successful copy displays a tick per request; a nonempty response draft displays its own tick (not an indication that JSON has passed validation). Clipboard paste reads text on click; if unavailable or empty, it focuses the response box and explains keyboard paste. Existing response drafts and import validation remain unchanged. Thumbnail variation prompts also display a tick after a successful copy.

Validation: 88 focused server and rendered-component checks, client production web build and server TypeScript. Tests cover overlay validation, all four templates, pixel bounds, unchanged original media, concurrent updates, replacement behavior, library readiness, HTTP SVG/PNG responses and action-button completion states. A generated four-template contact sheet was visually inspected. Test data is isolated from real series.
